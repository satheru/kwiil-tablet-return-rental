A Letter for Sam is a book that I would like to introduce. It is written by Elizabeth Messie. This book tells the story of Sam, who can't read There is Abe, Sam's friend. Abe can read, so he helps Sam. Sam, not being able to read, didn't care at first. A letter comes from Sam's uncle, but he can't read it. So Sam asks Abe for help. Abe reads it and Sam realizes that reading is important. So, Sam asks Abe to teach him to read. This book shows that asking for help with things you don't know is important. I recommend this book because the content is as simple as it is interesting, so anyone can read it. Reading it made me think about myself again. There was a word I didn't know in class. But I was too embarrassed to ask about it. Therefore, A Letter for Sam is a book that I would like to introduce. I want to tell you, this book gives you a chance to think about yourself.
